# クラウド保存先（Firebase）の作成手順

田んぼノートのデータを家族・スタッフで共有するための保存先を、Google の **Firebase** に作る手順です。
この手順でやるのは「保存先の用意」までです。アプリ側の対応（ログイン画面・同期）は、手順の最後に渡してもらう設定値を使って別途組み込みます。

- 費用：**無料プラン（Spark）のまま**で作れます。クレジットカードの登録は不要です。
- 所要時間：30分ほど
- 必要なもの：Google アカウント、パソコン（スマホでもできますが画面が狭く大変です）

> Firebase の画面は日本語表示を前提に書いています。画面の文言はときどき変わるので、少し違っていたら近い項目を選んでください。

---

## 0. 先に決めておくこと

| 項目 | 決めること | おすすめ |
|---|---|---|
| どの Google アカウントで作るか | プロジェクトの持ち主になります | **農場主（アプリを使う本人）のアカウント**で作るか、作業する人のアカウントで作ったあと、必ず農場主をオーナーに追加する（手順6） |
| プロジェクト名 | 画面に表示される名前 | `tanbo-note` |
| データの保存場所 | **後から変更できません** | `asia-northeast1`（東京） |

---

## 1. プロジェクトを作る

1. https://console.firebase.google.com を開き、Google アカウントでログインする
2. 「**プロジェクトを作成**」（または「Firebase プロジェクトを使ってみる」）を押す
3. プロジェクト名に `tanbo-note` と入れて進む
   - 下に表示される **プロジェクトID**（例：`tanbo-note-1a2b3`）を控えておく
4. 「Gemini」「Google アナリティクス」を有効にするか聞かれたら、**どちらもオフ**でよい
5. 「プロジェクトを作成」を押し、完了したら「続行」

料金プランは最初から **Spark（無料）** になっています。変更しないでください。

---

## 2. ウェブアプリを登録して設定値を取り出す

1. プロジェクトのトップ（「プロジェクトの概要」）で、**ウェブ（`</>` のアイコン）** を押す
2. アプリのニックネームに `tanbo-note-web` と入れる
   - 「Firebase Hosting も設定する」には**チェックしない**（公開は GitHub Pages で行っているため）
3. 「アプリを登録」を押す
4. 表示されるコードの中の、次のような部分をそのまま**コピーして保存**しておく（手順7で渡します）

```js
const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "tanbo-note-xxxxx.firebaseapp.com",
  projectId: "tanbo-note-xxxxx",
  storageBucket: "tanbo-note-xxxxx.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef123456"
};
```

5. 「コンソールに進む」を押す

> 後から見たいときは、左上の歯車 → 「プロジェクトの設定」→「全般」→ 下の「マイアプリ」にあります。

---

## 3. ログイン（Google ログイン）を有効にする

1. 左のメニュー「**構築**」→「**Authentication**」→「**始める**」
2. 「ログイン方法」タブで「**Google**」を選ぶ
3. 「**有効にする**」をオンにし、「プロジェクトのサポートメール」に自分のメールアドレスを選んで「**保存**」
4. 「**設定**」タブ →「**承認済みドメイン**」→「**ドメインを追加**」
   - `akinoririririri.github.io` を追加する
   - `localhost` は最初から入っているので、そのままでよい

---

## 4. データベース（Firestore）を作る

1. 左のメニュー「**構築**」→「**Firestore Database**」→「**データベースを作成**」
2. エディションを聞かれたら「**Standard**」を選ぶ
3. データベースID は `(default)` のまま
4. ロケーションは **`asia-northeast1 (Tokyo)`** を選ぶ（**後から変更できません**）
5. 「**本番環境モード**で開始する」を選んで「作成」

### セキュリティルールを設定する（必須）

ここを設定しないと、アプリからデータを読み書きできません。また、間違ったルールにすると他人にデータを見られるおそれがあります。

1. Firestore Database の画面上部の「**ルール**」タブを開く
2. 書かれている内容を**すべて消し**、このリポジトリの [`firestore.rules`](../firestore.rules) の中身を**丸ごと貼り付ける**
3. 「**公開**」を押す

このルールでは、次のようにアクセスを制限しています。

| 人 | できること |
|---|---|
| 農場の持ち主（owner） | すべての読み書き、メンバーの招待・削除 |
| 招待されて参加した人（member） | すべて読める。作業の予定・実績を書ける（田んぼ・作業者・資材の登録は不可） |
| それ以外の人・ログインしていない人 | 何も読めない・書けない |

> 「テストモード」でのルール（誰でも読み書きできる）には**絶対にしないでください**。

---

## 5. APIキーに利用制限をかける（推奨）

手順2の `apiKey` は、公開しているアプリの中に入るので誰でも見られます（Firebase ではこれは普通のことで、データは手順4のルールで守ります）。
それでも、ほかのサイトから使われないように、使える場所を制限しておきます。

1. https://console.cloud.google.com/apis/credentials を開く（上部のプロジェクト選択で `tanbo-note` を選ぶ）
2. 「API キー」の中の「**Browser key (auto created by Firebase)**」を押す
3. 「アプリケーションの制限」で「**ウェブサイト**」を選び、次の2つを追加する
   - `https://akinoririririri.github.io/*`
   - `http://localhost:8000/*`（開発用）
4. 「API の制限」は「キーを制限しない」のままでよい
5. 「保存」を押す（反映まで数分かかります）

---

## 6. 農場主をプロジェクトのオーナーにする

作業する人のアカウントでプロジェクトを作った場合は、必ず農場主を追加してください。作業した人と連絡が取れなくなっても、農場主が管理を続けられるようにするためです。

1. 左上の歯車 →「**ユーザーと権限**」
2. 「**メンバーを追加**」→ 農場主の Gmail アドレスを入れ、役割を「**オーナー**」にして追加
3. 農場主に届く招待メールを、農場主が承認する

---

## 7. 渡してほしいもの

次の3つを、田んぼノートの開発側（農場主）に渡してください。

1. **手順2の `firebaseConfig`**（`apiKey` から `appId` までの6項目）
2. **プロジェクトID**
3. 手順4で**ルールを公開した**こと、手順3で**承認済みドメインを追加した**ことの報告

`firebaseConfig` はパスワードではないので、チャットやメールで送って大丈夫です（アプリに組み込むと公開されるものです）。

### 渡してはいけないもの
- Google アカウントのパスワード
- 「サービスアカウントの秘密鍵（JSONファイル）」…この手順では**作成しません**。もし作ってしまったら削除してください。

---

## 今回はやらなくてよいこと

| 機能 | 理由 |
|---|---|
| Hosting | アプリの公開は GitHub Pages で行っています |
| Storage（写真の保存） | 写真の添付を作るときに追加します。いまの Firebase では有料プラン（Blaze）への切り替えが必要になるため、そのときに改めて相談します |
| Functions、Analytics、App Check | 当面は不要です |

---

## 無料プランで足りるか

無料プラン（Spark）の Firestore には、1日あたりの上限（読み取り約5万回、書き込み約2万回など）と、保存容量の上限（1GB）があります。
家族・スタッフ数人で田んぼの記録をつける程度なら、十分に収まります。上限を超えた場合も勝手に請求されることはなく、その日の読み書きが止まるだけです（翌日に回復します）。
