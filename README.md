# 田んぼノート（tanbo-note）

田んぼの作業管理アプリです。航空写真の地図で田んぼを登録し、作業の予定・指示・実績・農薬の使用をまとめて記録します。
スマホでもパソコンでも使えます。インストール不要で、ブラウザで開くだけで動きます。

## できること

| 画面 | 内容 |
|---|---|
| **今日** | その日の作業予定を一覧表示。「実績にする」で作業時間・作業した人を入れて完了。自分の担当だけの表示、作業指示書の印刷 |
| **地図** | 国土地理院の航空写真の上で、田んぼの角をタップして区画を登録（面積は自動計算）。今日の作業状況で色分け（オレンジ＝予定あり／緑＝完了／青＝作業なし）。現在地表示 |
| **予定・記録** | 月ごとの作業予定・実績の一覧、過去の未完了の予定の確認。作業の追加・編集・複製 |
| **集計** | 年ごとに、田んぼ別（作業時間・10aあたり人時・資材費・農薬使用回数）、作業の種類別、作業者別、資材の使用量を集計。作業記録のCSV出力（Excelで開けます） |
| **設定** | 作業者・資材（農薬・肥料など）・作業の種類の登録、この端末を使う人の設定、データの書き出し・読み込み |

### 農薬のチェック
資材の登録で「使用回数の上限（年）」と「収穫何日前まで」を入れておくと、作業を登録するときに次の場合に警告を出します。
- 同じ田んぼで同じ年に、上限の回数を超えて使う場合（予定も含めて数えます）
- 田んぼの「収穫予定日」までの日数が足りない場合

※ 使用基準は必ず農薬のラベルを確認して入力してください。

## データの保存について
今のバージョンでは、データは **それぞれの端末のブラウザの中** に保存されます（サーバーには送られません）。
- ほかの端末にデータを移すときは「設定 → データを書き出す」で作ったファイルを、移す先で「データを読み込む」してください。
- ブラウザのデータを消去すると、記録も消えます。ときどき書き出してバックアップしてください。

## 公開のしかた（GitHub Pages）
1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ（例：`main`）と `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/tanbo-note/` で開けます

スマホではブラウザのメニューから「ホーム画面に追加」すると、アプリのように使えます。

## 手元で動かす
ビルドは不要です。静的ファイルを配信するだけで動きます。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## これからの予定
- 家族・スタッフとのデータ共有（クラウド同期・ログイン）
- 作業予定の通知
- 写真の添付、生育記録
- 収穫・出荷の記録と収支
- 農薬の成分ごとの使用回数チェック

## ファイル構成
```
index.html            画面の枠
css/style.css         見た目
js/app.js             各画面と操作
js/map.js             地図（Leaflet・国土地理院タイル）
js/logic.js           面積計算・農薬チェック・集計
js/store.js           データの保存（今は localStorage）
js/util.js            共通の小さな関数
```

地図データ：[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)（航空写真・標準地図・地名検索）、Esri World Imagery（航空写真）／地図ライブラリ：[Leaflet](https://leafletjs.com/)
